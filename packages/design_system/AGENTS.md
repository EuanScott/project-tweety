# Design-system guidance

Read the [package README](README.md) for purpose, concepts, and extension paths.

- Keep this package presentation-focused and independent of `project_tweety`.
- Export public types from `lib/design_system.dart`; keep implementation under `lib/src/`.
- Primitive interfaces express app intent, not every Material or Cupertino option.
- Cover both platform presentations when changing an adaptive primitive.
